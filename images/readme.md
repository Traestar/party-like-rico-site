## Image Specs
- **Hero background:** 1920×1080px minimum, JPG, under 400KB compressed
- **Event cards:** 800×500px minimum, JPG
- **Gallery grid:** 800×800px or larger, JPG
- **Logo:** PNG with transparent background recommended
- **Event flyer:** Use original flyer file — site will NOT crop it

## Tips
- Compress images at tinypng.com before uploading
- Use JPG for photos, PNG for logos/graphics with transparency
- Name files exactly as listed above (case-sensitive on Netlify)
